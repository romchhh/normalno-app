# **Мета проєкту**

Розробити інтерактивний Telegram Mini App (TMA) — керований майстер підбору (Wizard), що розраховує персональний сценарій оновлення автомобіля виходячи з бюджету та комфортного щомісячного платежу клієнта, замість класичного каталогу з фільтрами.

Паралельно розробити бек-офіс (Адмін-панель) для управління сервісом: автопарком, користувачами, аналітикою та налаштуваннями алгоритму.

# **1\. Дизайн та візуальний стиль**

**Джерело дизайну:** Усі UI-компоненти, колірна гама, типографіка, стилістика кнопок, карток та інших елементів беруться напряму з офіційного сайту normalno-normalno.ua та затвердженого брендбуку компанії.

**Підхід:** Mobile-first інтерфейс із дотриманням гайдлайнів Telegram Mini Apps; темна / світла тема адаптується під брендбук NORMALNO.

# **2\. Загальні технічні вимоги**

**Платформа:** Telegram Mini App (Web App) \+ Web Admin Panel

### **Рекомендований стек**

* Frontend (Mini App / Admin Panel): React або Vue.js, Tailwind CSS (токени стилів налаштовані з брендбуку)

* Backend: Node.js (NestJS / Express) або Python (FastAPI)

* База даних: PostgreSQL

* Інтеграція: CRM Bitrix24 (створення угоди / ліда через REST API)

* Авторизація клієнтів: безпарольна, через Telegram.WebApp.initData (Telegram ID, First/Last Name, Username)

# **3\. Логіка калькулятора (Backend)**

### **Вхідні дані, які збирає Mini App**

* current\_car\_price — оцінка поточного авто (за замовчуванням $0)

* additional\_cash — додатковий старт (за замовчуванням $0)

* monthly\_payment — бажаний щомісячний платіж, USD

* term\_months — строк (за замовчуванням 36 міс)

### **Формула розрахунку максимального бюджету авто**

Total Start Budget \= current\_car\_price \+ additional\_cash

Max Car Budget \= Total Start Budget \+ (monthly\_payment × term\_months × k)

*де k — внутрішній коефіцієнт лізингу / кредитування, що коригується в конфігурації backend.*

# **4\. Сценарій та екрани Telegram Mini App**

### **Глобальний UI-шаблон (екрани 2–9)**

* Header: кнопка «Назад», логотип NORMALNO, Progress Bar (4 сегменти: Бюджет → Побажання → Варіанти → Стратегія)

* Footer: фіксована CTA-кнопка (якщо вибір не відбувається в 1 тап)

### **Схема переходів**

*Screen 1 (Hero) → Screen 2 (Start Option) → якщо «Є авто»: Screen 3 (Car Info) → Screen 4 (Price Valuation) → Screen 5 (Additional Cash); якщо «Немає»: одразу Screen 5\. Далі послідовно: Screen 6 (Monthly Payment) → Screen 7 (Term) → Screen 8 (Motivation) → Screen 9 (Car Prefs) → Screen 10 (Loader) → Screen 11 (WOW Results) → Screen 12 (Strategy Form) → Bitrix24 API.*

# **5\. Інтеграція з CRM Bitrix24**

При натисканні фінальної кнопки backend виконує POST-запит на Webhook/API Bitrix24 та створює Угоду (Deal) у заданій воронці.

### **Структура JSON-пакету**

{

  "fields": {

    "TITLE": "NORMALNO Strategy — \[Name\]",

    "NAME": "\[Telegram First Name\]",

    "PHONE": \[{"VALUE": "\[Phone Number\]", "VALUE\_TYPE": "WORK"}\],

    "UF\_TG\_ID": "\[Telegram ID\]",

    "UF\_TG\_USERNAME": "@\[Username\]",

    "UF\_CURRENT\_CAR": "Toyota RAV4 2011 (185k km)",

    "UF\_CURRENT\_CAR\_PRICE": 10000,

    "UF\_ADDITIONAL\_CASH": 2000,

    "UF\_TOTAL\_START\_BUDGET": 12000,

    "UF\_COMFORT\_PAYMENT": 550,

    "UF\_MAX\_CALCULATED\_BUDGET": 21000,

    "UF\_SELECTED\_CAR": "Lexus RX 350 2017 ($20,500 / $536/mo)"

}

# **6\. Адмін-панель (Back-Office / Web Admin)**

Веб-інтерфейс для контент-менеджерів, маркетологів та адміністраторів.

## **6.1. Аутентифікація та права доступу (RBAC)**

| Роль | Права доступу |
| :---- | :---- |
| **Super Admin** | Повний доступ: налаштування формул, управління доступами |
| **Content Manager** | Додавання / редагування машин, фотографій, ціноутворення |
| **Sales / View Only** | Перегляд бази користувачів та розрахунків без права редагування контенту |

## **6.2. Управління автопарком (Car Catalog Management)**

* CRUD авто: додавання, редагування, деактивація

* Поля картки авто: марка, модель, рік випуску, тип кузова

* Загальна ціна ($) — система автоматично вираховує щомісячний платіж для термінів 24 / 36 / 48 міс

* Мультизавантаження фотографій (з вибором головної обкладинки)

* Характеристики: пробіг, двигун, привід

* Статус: в наявності, під замовлення, заброньовано, продано

* Масовий імпорт / експорт: завантаження й оновлення каталогу через .csv / .xlsx

## **6.3. Управління користувачами та аналітика**

### **Таблиця користувачів**

* Telegram ID, Name, @username, телефон, дата входу, кількість розрахунків

### **Історія розрахунків**

* Введені дані: авто, платіж, строк, обрані мотиви

* Яке авто було обрано перед надсиланням заявки

* Логи передачі даних у Bitrix24 (Success / Failed)

## **6.4. Налаштування алгоритму та довідників**

* Конфігуратор калькулятора: редагування коефіцієнта k, діапазонів слайдера платежів, дефолтного строку

* Довідники: список мотивацій (екран 8\) та популярних марок (екран 9\)

## **6.5. Дашборд (Analytics)**

* Загальна кількість користувачів

* Конверсія воронки по кроках

* Середній комфортний платіж

* ТОП популярних марок

# **7\. Збереження стану (Persistence)**

* Дані зберігаються в localStorage / БД за telegram\_id

* При повторному вході користувач потрапляє на Екран 11 із можливістю відредагувати параметри («Мій NORMALNO»)
